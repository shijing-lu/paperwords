# 阅读模式需求规格说明书 (Reading Mode PRD)

## 1. 调研与认知科学背景

### 1.1 业界竞品与前沿模式调研
通过对当前主流外语精读与阅读工具（LingQ、Readlang、Beeline Reader、Smart Book、扇贝阅读、外刊精读）及语言习得理论的系统调研，总结出提升阅读理解能力的三大底层抓手：

| 工具 / 理论 | 核心机制 | 优缺点分析 | 本项目借鉴点 |
|---|---|---|---|
| **克拉申 $i+1$ 可理解性输入假说** | 读者只能在理解大部分内容（约 95%）的基础上，顺畅吸收新词和复杂句型。 | 传统软件把文章当单纯的“单词书伴读”，割裂了语境流动。 | **词库动态交叉染色**：自动将用户正在背的考研/GRE生词在文章中低侵入式标记，建立词汇在真实语境中的联结。 |
| **LingQ / Readlang** | 交互式点词查义、单词熟练度分级着色、生词伴读。 | 界面信息过载，容易频繁打断阅读心流。 | **悬浮伴读便签 + 边栏边注 (Margin Notes)**：保持极简纸质感，支持一键将文章生词收入到期复习池。 |
| **仿生阅读 (Bionic Reading) & 视线引导** | 词首粗体引导眼球跳跃（Saccade），降低大脑解码负担。 | 极度适合快速扫读与科技/考研长难篇章。 | **扫读视线加速开关**：支持一键开启词首视线聚焦引导。 |
| **考研/学术精读长难句意群切片法** | 将整篇长文分解为“段落 ➔ 句子 ➔ 意群”，逐句深度解析主谓宾定状。 | 传统长篇大段容易让考生迷失焦点。 | **全键盘逐句沉浸模式 (Sentence Focus)**：按 `J/K` 聚焦句子高亮，其余句子淡化，消除阅读焦虑。 |

## 3. 详细功能规格

### 3.1 文章导入与本地存储
- **导入形式**：
  1. **直接粘贴**：支持纯文本或 Markdown 格式粘贴。
  2. **本地文件拖拽**：支持 `.txt` 与 `.md` 文件解析。
  3. **预置优质篇章**：内置 3~5 篇经典考研英语真题阅读（如 2017 英语一经济危机、2019 科技反垄断）及《经济学人》精选样篇，开箱即读。
- **本地存储模型 (`articles` 表)**：
  ```typescript
  export interface ArticleItem {
    id: string;
    title: string;
    content: string; // 原始内容
    source?: string; // 来源 (如 Economist, 考研英语一)
    totalWords: number;
    lexicalDensity: number; // 考研/核心词汇覆盖率
    readProgress: number; // 阅读进度 (0-100%)
    createdAt: number;
    updatedAt: number;
  }
  ```

---

### 3.2 A4 纸感阅读器界面 (Light Academia Editorial)
- **视觉风格延续**：温暖纸白底色（`#FAF9F5`）、深墨色文字（`#1C1917`）、经典衬线排版（*Newsreader* 衬线正文，可切换现代无衬线），行高与字间距严格遵循现代西方排版黄金比例（line-height: 1.8，段间距 1.5rem）。
- **词库状态联动染色 (Cross-Referencing Tokenizer)**：
  - 自动将文章切分为句子和单词 Token，并与本地 Dexie 的 `words` 数据库碰撞：
    - **当前在学/生疏词 (Fuzzy/Unknown)**：带有温润的琥珀色下划波浪线或荧光标记，提示该词正是你在背的词。
    - **已掌握词 (Mastered)**：保持正常正文字色，避免视觉噪音。
    - **未收录生词**：悬停时显示轻微虚线。
- **伴读浮窗 (Floating Word Card)**：
  - 鼠标点击或键盘定位任一单词，浮现微型便签纸卡片：
    - 音标、词性、精准释义。
    - 按 `P` 原生发音。
    - `[+ 收入生词本 / 艾宾浩斯复习池]` 按钮，直接生成标准 `WordItem` 存入数据库。

---

### 3.3 三大阅读理解增强机制

#### 1. 经典沉浸读 (Immersive Reading)
- 大视野纸面呈现，右侧提供边注栏 (Margin Notes)，列出本文命中的所有考研核心词。

#### 2. 逐句意群聚焦读 (Sentence Focus by J/K)
- 键盘盲操：按 `J` 下一句，按 `K` 上一句。
- 当前句以高亮框聚焦，其余段落半透明淡出（透明度 0.35），强迫大脑注意力集中在当前长难句上。

#### 3. 语境挖空测试读 (Context Cloze Recall)
- 系统自动将命中词库的考研词用 `:spoiler[黑幕]` 遮挡为 `[______]`。
- 读者边读文章边结合上下文猜词，按 `Space` 或点击瞬间揭示，完成最高阶的语境提取训练。

---

## 4. 非功能性需求
- **分词性能**：千字长文在 16ms 内完成 Tokenization 与数据库词汇匹配，阅读界面滚动 60+ FPS。
- **离线能力**：文章内容与伴读注释完全存储在 IndexedDB，无任何服务器请求。
