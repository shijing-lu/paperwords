# 需求规格说明书 (PRD v2.0) - PaperWords 流式纸感背单词

## 1. 版本迭代背景与设计原则
在 v1.0 基础（A4 纸感高密双列扫读、艾宾浩斯双层算法、本地 Dexie 存储、全键盘盲操）之上，v2.0 重点解决**“信息过载无目标”**与**“被动复习易遗忘”**两大痛点。
核心原则从“全量字典浏览”转变为**“任务闭环驱动”**：
1. **视图分流**：将全库分为「今日新学（定量）」、「到期复习（主动回忆）」、「全量纸单归档」与「生词错词池」。
2. **跨平台置顶提醒**：建立到期提醒通知系统，确保用户在 Windows 其他工作界面也能收到强提醒。
3. **三维主动回忆（Active Recall）自测**：适配考研/GRE 核心笔记的“英译中”、“中译英”、“真题挖空”三轮递进训练。

## 2. 核心功能需求拆解

### 2.1 多页面 / 任务视图分流架构

```
PaperWords 顶层导航
├── 1. 📊 控制台 (Dashboard)：复习日历、遗忘曲线健康度、今日任务一键启动
├── 2. 📖 今日新学 (Today's Plan)：每日定量新词（默认 50 词，可配置），独立 A4 刷词流
├── 3. ⏰ 待复习池 (Due Reviews)：基于艾宾浩斯时间戳（5m/30m/12h/跨天）自动归集的到期复习专区
├── 4. 🔥 生词重点区 (Stumble Pool)：自动聚合打标为“生疏 (3)”与“模糊 (2)”的词汇
└── 5. 📑 词库归档 (Archive & A4 Sheets)：全量词汇浏览、List 翻页检索、JSON/TXT 导入导出
```

#### (1)「今日新学」页面 (Today's Learn Page)
* **定量配置**：用户可自定义“每日新学词数”（如 30 / 50 / 80 词）。
* **独立进度闭环**：该页面只切出今日分配的指定词量（例如 50 词切为两张 A4 纸单），刷完即算今日新词目标完成。
* **打标流**：首次通读一遍后，未掌握词自动流入待复习队列。

#### (2)「待复习」页面 (Due Reviews Page)
* **动态聚合**：查询数据库中所有 `nextReviewDate <= Date.now()` 的单词，按照紧急度从高到低排列。
* **批量复习 A4 纸单化**：将所有到期复习词动态打包为复习纸单（每 30 词一组），依然沿用高密双列排版。
* **自测完成推移**：打标“1（熟练）”后立即推移至下一艾宾浩斯周期并从本页面移除；打标“2/3”则保留在短期回看池。

### 2.2 Windows 跨应用置顶提醒机制 (Always-on-Top & Alert)

#### 技术实现路径对比与分层设计：
1. **Web 层解决方案（原生 Web Notification API + 焦点强唤醒）**：
   * **系统级托盘通知**：当艾宾浩斯到达 5 分钟、30 分钟或定时节点时，调用 Windows 原生通知中心（Action Center）弹出桌面 Toast。
   * **音频蜂鸣与强提示**：伴随专属提示音，通知附带快捷操作按钮 `[立即复习]`。
   * **点击强置顶聚焦**：用户在任何 Windows 窗口（玩游戏、敲代码、看文档）点击通知，浏览器立即自动置顶并跳转至「待复习」页面。
2. **桌面级彻底置顶方案（Tauri / Electron 浮窗轻量包装）**：
   * 采用 Tauri（体积仅 3MB，内存占用 < 20MB）打包为原生 Windows 应用。
   * 支持系统级全局快捷键唤醒。
   * 调用 `window.setAlwaysOnTop(true, 'screen-saver')`，时间一到直接在 Windows 屏幕右上角或中央弹出悬浮透明小纸片，强迫主动回忆自测后自动消失。

### 2.3 三维自测模式（深度适配考研与学术笔记）

从单一的“英文看释义”，升级为支持快捷键一键切换的三维训练模式：

| 模式 | 页面展示 | 黑幕遮罩内容 | 键盘操作 | 训练目标 |
|---|---|---|---|---|
| **模式 A：英译中** | 英文原词 + 音标 + 考点短语 | 中文释义 `:spoiler[...]` | `Space` 刮开释义 | 阅读识别速度 |
| **模式 B：中译英** | 词性 + 中文释义 + 考点中文 | 英文拼写 `:spoiler[...]` | `Space` 刮开拼写 / 键盘盲打核对 | 写作与主动提取 |
| **模式 C：真题挖空** | 真题例句挖空 `______ nation` | 空格处英文 `:spoiler[...]` | `Space` 揭示真题原词 | 语境搭配与真题实战 |

### 2.4 学习体验与辅助特性完善

1. **倒计时悬浮胶囊 (Countdown Capsule)**：
   * 界面右上角常驻当前最近一次复习的倒计时标签（例如：`⏱ 距第 1 遍 5min 回刷还剩: 03:45`），到点呼吸变红。
2. **机械键盘音频反馈 (Haptic Audio Feedback)**：
   * 按下 `1/2/3` 打标、按 `Space` 刮开黑幕、按 `P` 发音时，内置轻快短促的打字机音效，强化连续盲操的多巴胺正反馈。
3. **遗忘热力图与艾宾浩斯日历**：
   * 便当盒卡片增加类似 GitHub Contribution 的 30 天刷词热力矩阵，清晰可见每天的投入度。
