# 📜 PaperWords (纸感词语)

> **流式纸感背单词 · 艾宾浩斯高密扫读 · 现代认知科学词汇工作台**

PaperWords 是一款专为**考研英语、GRE、托福、雅思、四六级备考与深度英文外刊阅读者**设计的现代化高效率单词研读工具。

它深度融合了《杨鹏十七天搞定 GRE 单词》高密扫读心法、SM-2 艾宾浩斯动态间隔重复记忆算法、红宝书滤镜遮红自测、全功能键盘盲操与语境精读伴读系统，告别传统背词软件“一屏一词”的低信息密度与假熟错觉。

---

## ✨ 核心特性

### 1. 📄 A4 仿物理纸感排版与流式多栏布局
- **学术级视觉排版**：选用 Classic Academic Serif（Newsreader）与 Modern Clean Sans 字体组合，复刻真实纸张水墨微质感。
- **动态分栏自适应**：支持 2 栏、3 栏、4 栏自由切换，一屏收纳 30~50 词，实现快速眼动大视野扫读。
- **三大自测视图**：
  - **红宝书遮红模式 (Mask)**：遮挡中文释义，按 `Space` 或点击局部刮开自测。
  - **拼写回想模式 (En-to-Cn / Cn-to-En)**：隐去英文拼写，强化主动拼写检索。
  - **真题挖空模式 (Cloze)**：考研历年真题语境自动挖空，在语境中识词。

### 2. ⚡ 全键盘盲操与免点击极速过滤
- **极速键位映射**：
  - `J` / `K` 或 `↓` / `↑`：上下行极速扫读
  - `H` / `L` 或 `←` / `→`：跨栏二维移动
  - `Space`：刮开/隐藏当前单词中文释义
  - `1` / `2` / `3`：分别标记「熟练」、「模糊」、「生疏」
  - `P`：标准真人语音朗读发音
- **常驻一步过滤**：每张单词卡片常驻轻量「1 熟 2 糊 3 生」操作按钮，无需选中卡片即可单次点击秒级过滤出队。

### 3. 🔄 今日新学递进淘汰机制 (杨鹏心法)
- **多轮循环淘汰**：第一轮全览筛查后，系统自动提取生疏/模糊难词生成下一轮攻坚队列，直至当日配额单词全部达成首次熟练（100% 毕业）。
- **一轮首通率统计**：精准衡量当日词汇硬掌握水平，激励高效攻坚。

### 4. 🧠 认知防假熟与 8 阶梯艾宾浩斯到期复习
- **SM-2 科学间隔曲线**：单词毕业后自动推入 8 级复习日程（5分钟、30分钟、12小时、1天、2天、4天、7天、15天）。
- **实时倒计时与强提醒**：顶部导航栏常驻复习倒计时胶囊，支持自定义到期词汇阈值通知与桌面级声音提示。

### 5. 📊 今日学习统计看板与 5 阶记忆热度色谱
- **水墨琥珀色渐变系统**：根据今日与累计学习频次，自动为单词渲染不同深浅底色：
  - `1 次`：极浅水墨灰底（初识低心智负担）
  - `2 次`：淡麦芽黄（轻度巩固）
  - `3 ~ 4 次`：醇厚琥珀金（强化记忆）
  - `5 ~ 6 次`：焦糖暖橙色（`⚡ 重点关注`）
  - `7+ 次`：火漆印赭红（`🔥 难词攻坚`）
- **可视化看板**：统计今日刷词总量、复习频次梯级分布及重点难词清单。

### 6. 📰 语境精读与 16,800+ 离线大词典
- **外刊与真题分词伴读**：文章划词智能解析，支持逐句聚焦（`J`/`K`）、译文折叠与双语朗读。
- **16,800+ 离线大词典**：整合高中、四六级、专四专八、考研、托福、雅思核心词库，离线毫秒级出释义与英美音标。
- **形态还原引擎 (Lemmatizer)**：点击复数（`bodies -> body`）、分词（`governing -> govern`）、不规则变化（`went -> go`）自动还原词根，一键收入生词本。

### 7. 🤖 AI 词根词缀拆解与智能联想
- **双模接入支持**：支持配置自有 API Key（OpenAI / Gemini / DeepSeek 等主流大模型）或使用订阅接入。
- **词源拆解**：点击展开词根、前缀、后缀分解与记忆故事，破解机械死记硬背。

## 🛠️ 技术栈

- **前端框架**：[React 19](https://react.dev/) + [TypeScript 5](https://www.typescriptlang.org/)
- **构建工具**：[Vite 6](https://vite.dev/)
- **样 式**：[TailwindCSS v4](https://tailwindcss.com/)
- **动 画**：[Framer Motion](https://www.framer.com/motion/)
- **本地存储**：[Dexie.js](https://dexie.org/) (基于浏览器 IndexedDB，离线秒级检索)
- **语 音**：Web Speech API (真人语音合成)
- **音 效**：Web Audio API (机械键盘敲击段落感与通关礼花音效)

## ⌨️ 快捷键盲操速查指南

| 按键 | 功能说明 |
| :--- | :--- |
| <kbd>J</kbd> / <kbd>↓</kbd> | 向下移动光标至下一词 |
| <kbd>K</kbd> / <kbd>↑</kbd> | 向上移动光标至上一词 |
| <kbd>H</kbd> / <kbd>←</kbd> | 向左跨栏切换 |
| <kbd>L</kbd> / <kbd>→</kbd> | 向右跨栏切换 |
| <kbd>Space</kbd> | 刮开 / 隐藏当前单词的中文释义 |
| <kbd>1</kbd> | 标记为「熟练」，触发成功反馈音 |
| <kbd>2</kbd> | 标记为「模糊」，留存下一轮硬骨头攻坚 |
| <kbd>3</kbd> | 标记为「生疏」，留存下一轮硬骨头攻坚 |
| <kbd>P</kbd> | 发音朗读当前单词 |
| <kbd>M</kbd> | 循环切换全览自测模式 (全显 / 遮红遮义 / 极速) |
| <kbd>R</kbd> | 切换识记方向 (英译中 / 中译英 / 真题语境挖空) |
| <kbd>?</kbd> | 打开键盘快捷键全览面板 |

## 🚀 快速上手

### 1. 克隆代码仓库
```bash
git clone https://github.com/shijing-lu/paperwords.git
cd paperwords
```

### 2. 安装依赖项
```bash
npm install
```

### 3. 启动开发服务器
```bash
npm run dev
```
启动后在浏览器打开 `http://localhost:5173` 即可开始使用。

### 4. 构建生产产物
```bash
npm run build
```

## 📄 词库导入与管理

支持导入常见格式的词汇文件：
- **JSON**：`[{"word": "abandon", "phonetic": "/əˈbændən/", "definition": "vt. 放弃"}]`
- **CSV / TSV**：由墨墨背单词、不背单词、欧路词典导出的生词本数据
- **TXT**：一词一行或带有制表符/逗号的纯文本

系统内置了考研英语 335 核心词串讲、GRE 核心 200 词以及精选真题阅读篇章，导入即可开箱即学。
